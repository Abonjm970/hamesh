# هامش

هامش تطبيق عربي محلي يساعدك على قراءة ملفات PDF وكتابة ملاحظات مرتبطة بكل صفحة.

## ماذا يمكنك أن تفعل؟

- قراءة ملف PDF داخل المتصفح دون تعديل الملف الأصلي.
- كتابة ملاحظات في هامش جانبي وهامش سفلي لكل صفحة.
- استخدام النص الغامق والقوائم وتغيير حجم الخط.
- وضع فواصل ملوّنة على الصفحات المهمة والانتقال بينها بسرعة.
- تغيير حجم الهوامش حسب المساحة التي تحتاجها.
- تصدير المستند مع ملاحظاته إلى PDF.
- تصدير الملاحظات إلى ملف Markdown.
- تبديل الوضع الفاتح والداكن.

## الخصوصية

تتم معالجة ملفاتك وملاحظاتك على جهازك فقط. لا تحتاج إلى حساب، ولا تُرفع ملفات PDF إلى أي خادم، ولا يستخدم التطبيق تخزينًا تلقائيًا.

## طريقة الاستخدام

1. اختر **أنشئ مذكرة** لفتح ملف PDF جديد.
2. اكتب ملاحظاتك في الهامش الجانبي أو السفلي.
3. استخدم شريط التنسيق لتغيير شكل النص أو حجمه.
4. تنقّل بين الصفحات باستخدام السهمين.
5. اختر **حفظ** لتنزيل مذكرة قابلة للفتح لاحقًا بامتداد `.hamsh`.
6. اختر **افتح مذكرة** لفتح ملف `.hamsh` محفوظ مسبقًا.

## الملفات المصدّرة

- ملف `.hamsh`: يحفظ ملف PDF الأصلي وملاحظاتك وإعدادات العرض معًا.
- ملف PDF: نسخة من الصفحات مع الهوامش والملاحظات.
- ملف Markdown: نص الملاحظات مرتبًا حسب أرقام الصفحات.

## العمل دون اتصال

بعد تحميل التطبيق وموارده أول مرة، يمكن استخدامه دون اتصال بالإنترنت. قد تحتاج الخطوط إلى اتصال أولي حتى تُحمّل.
