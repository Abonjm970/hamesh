# هامش — Hamesh

تطبيق ويب عربي محلي لقراءة ملفات PDF وكتابة ملاحظات مرتبطة بكل صفحة، في هامش جانبي وهامش سفلي. يحفظ التطبيق ملف PDF والملاحظات وإعدادات العرض معًا في ملف واحد بامتداد `.hamsh`.

## المزايا

- قراءة PDF داخل المتصفح دون تعديل الملف الأصلي.
- ملاحظات مستقلة لكل صفحة في هامش أيمن وهامش سفلي.
- تنسيق أساسي: غامق، قوائم، وحجم خط صغير/عادي/كبير.
- تغيير حجم الهوامش وحفظ يدوي قابل للنقل.
- معالجة محلية؛ لا حسابات ولا رفع للملفات ولا تخزين تلقائي.

## التشغيل محليًا

يتطلب التطبيق خادم HTTP بسيطًا لأنّه يستخدم ES Modules وPDF.js:

```bash
git clone https://github.com/<username>/<repository>.git
cd <repository>
python3 -m http.server 4173
```

افتح بعدها: <http://localhost:4173/>

## النشر على GitHub Pages

المشروع ثابت بالكامل ولا يحتاج إلى build step. يوجد workflow جاهز في [`.github/workflows/pages.yml`](.github/workflows/pages.yml):

1. ارفع المشروع إلى مستودع GitHub.
2. من **Settings → Pages** اختر **GitHub Actions** كمصدر النشر.
3. ادفع أي commit إلى فرع `main`؛ سيُنشر الموقع تلقائيًا.

يمكن أيضًا تشغيل workflow يدويًا من تبويب **Actions**. لا تضع ملفات PDF أو ملفات `.hamsh` شخصية داخل المستودع.

## بنية المشروع

| الملف | الغرض |
| --- | --- |
| `index.html` | هيكل الواجهات ومساحة العمل |
| `styles.css` | التصميم المتجاوب واتجاه RTL |
| `app.js` | الحالة، PDF.js، المحررات، التعقيم، والاستيراد والتصدير |
| `favicon.svg` | أيقونة التطبيق |
| `PRD.md` | متطلبات المنتج ونطاق الإصدار |
| `AGENTS.md` | إرشادات التطوير والاختبار |

## الاختبار قبل الدمج

```bash
node --check app.js
```

ثم اختبر يدويًا في Chrome أو متصفح حديث: إنشاء مذكرة متعددة الصفحات، الكتابة والتنسيق، التنقل ذهابًا وإيابًا، الحفظ وإعادة الفتح، ورسائل الملفات غير الصالحة.

## الخصوصية والاعتماديات

الملفات والملاحظات لا تغادر جهاز المستخدم. يعتمد التطبيق على PDF.js وخطّي Google Fonts عبر CDN؛ لذلك يلزم اتصال بالإنترنت عند تحميل الصفحة لأول مرة إذا لم تكن هذه الموارد مخزنة مؤقتًا.
